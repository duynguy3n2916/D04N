Cách làm

  • Chỉ dùng CSS và vài dòng JS thuần, không thêm thư viện nào.
  • Không đổi logic, API hay luồng dữ liệu; chỉ thay giao diện.
  • Có nút “Giảm hiệu ứng” và tự tôn trọng cài đặt giảm chuyển động của hệ điều hành.

Phạm vi sửa (sau khi duyệt)

  • frontend/src/styles.css — token màu, nút, hiệu ứng
  • components/AppShell.tsx, pages/Learn.tsx, pages/Lesson.tsx
  • pages/items/QuizItem.tsx, components/TutorPanel.tsx, components/Mascot.tsx, pages/Login.tsx
  • Cuối cùng chạy npm run build để cập nhật frontend/dist
